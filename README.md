# Smart Product Inquiry Chatbot
This project involved building an intelligent chatbot designed to help customers inquire about products available at the company. The chatbot is capable of answering questions related to product names, prices, availability, and detailed specifications.

The process began with collecting and cleaning real product data, including handling missing values, standardizing text, and structuring the dataset for efficient use. An NLP model was developed to understand various customer queries, even when phrased partially, indirectly, or informally. The model was enhanced using OpenAI's ChatGPT API to ensure natural and context-aware responses.

The chatbot supports features like:

Recognizing partial or misspelled product names.

Suggesting similar products when an exact match isn’t found.

Providing quick access to product prices and key information.

Handling both English and Arabic input (if applicable).

The system was deployed using Flask, providing a simple and responsive web interface. This allowed real-time interaction between users and the chatbot, simulating a smart customer support experience.

Technologies used in this project include:

Python for backend logic and data processing.

Pandas and NumPy for data cleaning and preparation.

OpenAI API (ChatGPT) for language understanding and dynamic response generation.

Flask for deploying the chatbot as a web service.

Basic HTML/CSS for creating the frontend interface.

This project reflects key competencies in data preprocessing, NLP, model integration, and API-based deployment. It also highlights the ability to build end-to-end AI solutions that solve real-world business problems through automation and intelligent interfaces.
